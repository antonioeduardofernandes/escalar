# Escalar

Sistema de gestão de escalas hospitalares em desenvolvimento.

## Sobre o projeto

O **Escalar** tem como objetivo apoiar a gestão de escalas hospitalares, reunindo regras de negócio, cadastros, planejamento de escalas e plantões, dimensionamento, acompanhamento de ocorrências, fechamento e relatórios em um sistema organizado e rastreável.

Este repositório centraliza o código e a documentação oficial do projeto.

## Organização e continuidade

O desenvolvimento deve preservar a consistência entre requisitos, regras de negócio, arquitetura, interface, permissões, integridade dos dados e auditoria.

As informações do projeto devem ser mantidas atualizadas para que o trabalho possa ser retomado com segurança, sem depender exclusivamente do histórico de conversas.

Decisões, requisitos documentados, propostas técnicas e questões pendentes devem ser identificados separadamente. Alterações relevantes devem ser refletidas nos documentos correspondentes, e o estado do projeto deve indicar a próxima ação recomendada.
