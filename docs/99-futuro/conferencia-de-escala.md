# Futuro — Conferência Automática da Escala

> Este documento descreve uma evolução planejada e não deve ser tratado como regra obrigatória da versão atual.

## 1. Objetivo

Permitir que o sistema realize conferência automática da escala e identifique divergências ou possíveis erros.

---

## 2. Princípio

A automação deve identificar problemas e propor correções.

Ela não deve alterar silenciosamente a escala.

> Automação propõe. O gestor decide.

---

## 3. Divergências

A conferência poderá identificar, entre outras situações já previstas pelo domínio:

- conflitos de jornada;
- intervalos incompatíveis;
- problemas de cobertura;
- inconsistências de lotação;
- divergências de carga.

---

## 4. Regra

Uma divergência identificada não deve ser automaticamente corrigida sem decisão humana.

---

## 5. Status

Este documento representa uma evolução futura e não deve ser usado pelo agente como justificativa para implementar funcionalidades que ainda não tenham sido aprovadas.
